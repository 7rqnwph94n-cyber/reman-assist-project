Setup Instructions

  1. Create a QuickBooks Online app at developer.intuit.com
  2. Set the redirect URI to: {{ request.url_root }}admin/quickbooks/callback
  3. Add your Client ID and Secret to environment variables: QUICKBOOKS_CLIENT_ID, QUICKBOOKS_CLIENT_SECRET
  4. Set QUICKBOOKS_REDIRECT_URI to match the redirect URI above
  5. Generate an encryption key: python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
  6. Set QB_ENCRYPTION_KEY and ENABLE_QUICKBOOKS=true
